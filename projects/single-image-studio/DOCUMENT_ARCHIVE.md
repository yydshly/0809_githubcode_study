# 文档归档 / 附件处理方案

状态：内部产品 Alpha；纯本地组合流程。

## 固定流程

```text
手动选四角
→ 透视裁正
→ 原色 / 清晰彩色 / 灰度 / 高对比黑白
→ 最长边限制
→ JPEG
→ 压缩到附件上限
→ 重开核对
```

用户仍负责四角位置和文档效果；系统只组合已有确定性能力。第一版默认清晰彩色、1600 px、1 MB，允许改为 100–10240 KB。

## 边界

- 不调用模型或远程服务。
- 不做 OCR、自动找边、曲面展开、去反光或补字。
- 弯曲页面、强模糊、折痕和阴影仍会保留。
- 文件上限未达标时必须明确显示。
- 独立“文档 / 平面裁正”工具继续保留，适合不需要 JPEG 附件压缩的任务。
