- 上传使用原生 `input[type=file][multiple]`；推荐、主图、文件、生成和下载均为原生按钮。
- 推荐使用 `aria-pressed`，文件使用 `aria-current`，状态使用 `role="status"` / `aria-live`。
- CSS 为按钮、链接、输入、文本域和 summary 定义统一 `:focus-visible`。
- `prefers-reduced-motion: reduce` 下动画和过渡缩短到近乎即时。
- 当前浏览器的 CUA `Tab` 注入没有移动真实焦点，因此物理键盘完整重放仍待普通桌面浏览器复测。

## 能力边界

- 当前“推荐预演”根据图片数量和产品结构规则工作，能够验证推荐位置、文案、选择与下游结果，但不是视觉理解模型。
- 当前视觉结果由浏览器 Canvas 确定性合成，未调用在线 ImageGen。

## 当前结论
