# 小角度水平校正工具合同

状态：实现中。本文件先于代码修改冻结交互与几何边界；它不是自动地平线识别或透视校正声明。

## 用户目标

用户在照片略微歪斜时，可以在现有编辑流程中手动拉直画面，并立即看见与最终下载一致的结果。工具应直观、可撤销，不要求账号、模型或外部 API。

## 主要流程

1. 用户上传图片并进入任一可运行的编辑任务。
2. 在“画面与尺寸”中拖动“水平校正”滑杆，范围 `-10°` 至 `+10°`，步进 `0.1°`。
3. 预览实时旋转并等比放大到覆盖画布，避免出现透明空角；界面明确提示这会轻微裁掉边缘。
4. 用户可一键归零，也可使用现有撤销、重做和全部重置。
5. 裁剪、尺寸上限、增强与导出继续使用同一份编辑状态；下载结果必须与预览一致。

## 视觉与交互合同

- 页面类型：功能型混合工作台；沿用当前产品的卡片、表单、预览与结果层级，不新增独立工具墙。
- 主动作仍是生成结果；水平校正是“画面与尺寸”中的次级局部控制。
- 滑杆旁持续显示当前角度，零值显示 `0°`，正值显示 `+N°`。
- 提供明确的“归零”动作，不依赖双击或隐藏手势。
- 预览不得出现因小角度旋转产生的透明三角；为此采用统一覆盖缩放，并在控件附近说明会裁去少量边缘。
- 预览与导出共同使用渲染计划，不能分别实现近似逻辑。

## 几何合同

- `rotation` 继续只表示 `0/90/180/270` 的整角旋转；新增 `straighten` 表示 `[-10, 10]` 的有限小数角度，两者不能混用。
- 小角度校正不改变编辑画布的宽高与既有裁剪坐标系。
- 对变换后宽高 `W × H` 和小角度 `θ`，统一覆盖缩放为：

  `max(|cos θ| + H/W × |sin θ|, |cos θ| + W/H × |sin θ|)`

- `straighten = 0` 时覆盖缩放必须严格为 `1`，保持既有结果。
- 整角旋转、翻转、小角度校正、裁剪、缩放与增强必须按单一固定顺序渲染。
- 输出尺寸上限仍限制最长边，不因自动覆盖缩放改变最终输出尺寸。

## 能力边界

本阶段提供：手动小角度拉直、自动覆盖裁边、实时预览、撤销/重做/重置、与下载一致的本地渲染。

本阶段不提供：自动检测地平线、建筑透视/梯形校正、镜头畸变校正、内容感知补边、超出 `±10°` 的任意旋转。界面和文档不得暗示这些能力已经存在。

## 状态覆盖

- 默认：`0°`，旧图片与旧任务行为不变。
- 编辑中：滑杆输入仅更新实时预览；提交时写入历史。
- 边界：`-10°`、`+10°` 可用；越界和非有限值拒绝。
- 撤销/重做：角度与其他设置一起恢复。
- 重置：回到 `0°`。
- 错误：非法设置不得生成不可信结果。

## 验收

- 几何单测证明零角、正负对称、长宽图覆盖缩放和角点覆盖。
- 状态、会话、工作区与渲染测试覆盖角度持久化、历史和预览/下载同源。
- 产品文案测试覆盖范围、归零动作和“轻微裁边”的诚实说明。
- 全量项目验证通过。
- 浏览器视觉复核至少覆盖：宽图、竖图、`90° + 1:1 + 小角度校正`。若当前自动浏览器能力不可用，必须明确记录未取得视觉证据，不以单测代替视觉结论。
