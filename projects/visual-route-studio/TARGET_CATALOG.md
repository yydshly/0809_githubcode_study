# 原图成品目标探索目录

> 状态：方向探索 D0。当前只扩展目标空间，不代表已经选择产品，也不代表存在用户需求证据。

## 1. 先定义“目标”，再讨论怎么做

本项目中的目标不是某个 Skill、模型、风格或处理步骤，而是用户最后要拿走和使用的成品。

例如：

- “拼贴”“重绘”“抽象”“半色调”“保留原图”是改造方式，不是目标。
- “活动海报”“播客封面”“六页图片小志”“舞台屏幕”才是目标。
- 同一种目标可以调用多种改造方式；同一种改造方式也可以服务多个目标。

统一目标定义为：

> **成品目标 = 载体 + 使用位置 + 输入规模 + 原图保留等级 + AI 改造幅度 + 必须文字 + 输出规格**

用户不需要填写这条公式。产品只需要让用户通过推荐、选择或一句话描述把它确定下来。

## 2. 三种目标进入方式

### A. AI 根据原图推荐

用户先上传图片。系统读取图片数量、主体、场景、构图、留白、色彩、清晰度、系列关系与可裁切空间，给出三个不同的成品目标，并显示推荐理由和预览。

AI 只能说“这张图适合做什么”，不能声称知道用户真实用途。用户必须确认目标。

### B. 用户从目标目录选择

用户先选“海报”“封面”“图片小志”“明信片套装”等明确成品，再上传原图。系统按目标要求提示还缺少的图片、文字和规格。

### C. 用户直接描述结果

用户可以说：“把这六张旅行照片做成一本可以发朋友圈的竖版小志”或“把这张旧照片做成周年活动主视觉”。AI 将自然语言归入目标卡，并让用户确认输出。

三种入口最终都落在同一种目标卡上，不形成三套产品。

## 4. 改造方向是目标的第二层

目标确定后，用户才需要选择图片如何变化。现有能力可归纳为九种方向：

| 方向 | 结果特征 | 默认原图保留程度 |
| --- | --- | --- |
| 原图增强 | 调色、裁切、层级、真实排字 | 高 |
| 编辑拼贴 | 多图组合、节奏、照片窗 | 中高 |
| 记忆重绘 | 保留人物 / 场景关系，重新绘制画面 | 中 |
| 物件遗迹化 | 将照片转成纸张、印刷、档案材料感 | 中高 |
| 关系抽象 | 将方向、密度、距离、分组转成图形 | 低，但需保留事实来源 |
| 单一隐喻 | 从原图提炼一个核心视觉概念 | 中低 |
| 限色 / 半色调 | 转成可印刷的材料语言 | 中 |
| 图案化 | 从局部形状、颜色生成重复纹样 | 低 |
| 连续叙事 | 多图排序并形成开场、展开、转折、收束 | 按页面变化 |

一个目标应至少给用户三种可理解的方向预览，例如同一张活动照片可以得到“原图主导”“编辑拼贴”“图形抽象”三种方案，而不是展示 Skill 名称。

## 5. AI 如何根据原图推荐目标

| 原图信号 | 优先推荐的成品目标 |
| --- | --- |
| 单个人物、动作清楚、背景可分离 | 人物海报、文章封面、引语卡、招聘卡、编辑跨页 |
| 单个物件、材质清楚、轮廓完整 | 产品主视觉、物件故事卡、标签、礼盒卡、图案化表面 |
| 建筑 / 房间 / 街景、空间关系明确 | 空间网页、旅行海报、明信片、导览页、灯箱、销售折页 |
| 4–8 张同一事件或旅程照片 | 图片轮播、视觉小志、摄影故事、纪念册、故事墙 |
| 多张旧照或档案图 | 周年档案组、口述史小册、历史墙、照片遗迹卡、纪念盒 |
| 色彩、纹理或局部细节强，叙事弱 | 限色艺术海报、包装纸、织物图案、印花、贴纸系列 |
| 有明显留白或单一视觉锚点 | 图书封面、报告封面、播客封面、活动海报、短视频定帧 |
| 有清楚路径、方向、密度或分组关系 | 关系研究卡、构图讲解海报、抽象主视觉、方法卡 |
| 多个同类产品 / 人物 / 场次 | Lookbook、目录缩略图组、发布包、批量视觉系统 |
| 清晰度低但情感或历史价值高 | 旧照复兴、照片遗迹卡、家庭记忆页、口述史作品 |

推荐时还要明确提示：图片本身只能判断“适合”，无法判断“需要”。用途、渠道、文字、印刷或屏幕规格仍须用户确认。

## 6. 每张目标卡应展示什么

后续探索不先做完整应用，而先为候选目标制作统一目标卡：

1. 成品名称和真实使用位置。
2. 一张代表性结果预览，而不是流程图。
3. 最少需要几张原图、是否需要同一系列。
4. 需要用户提供的真实文字。
5. 默认保留原图到什么程度。
6. 可选择的三种 AI 改造方向。
7. 最终输出的数量、尺寸和文件类型。
8. 可以继续扩展成哪些成品套件。
9. 依据等级：现有 Skill 研究已出现 / 能力相邻扩展 / 仍需验证。

## 7. 下一轮探索方法

当前不从 96 个目标中直接选 MVP，也不继续围绕 StoryFold 的既有页面扩建。下一轮应先做广度验证：

1. 从十二类中各选一个代表目标，共十二张目标卡。
2. 为同一组原图生成跨类别推荐，验证 AI 是否能给出真正不同的结果，而非换风格。
3. 让用户可以改选目标或直接输入自定义目标。
4. 记录哪些目标需要一张图、哪些需要多图、哪些必须有文字或规格。
5. 只有当目标卡和结果预览足够清楚，再收敛首版产品。

十二类的第一轮代表性目标已经整理为 [TARGET_CARDS.md](TARGET_CARDS.md)，统一使用同一组六张原图比较，并增加“直接推荐 / 条件推荐 / 仅用户指定”的推荐权限。

## 8. 当前结论

产品不应被预先固定为“图片小志”或“海报生成器”。更准确的探索对象是：

> **一个以原图为起点、先帮助用户确定成品目标，再调用多种图片能力完成改造和输出的电脑网页产品。**

十三个 Skill 提供的是后台可组合能力；96 个成品目标构成前台探索空间。最终产品边界要由目标卡、结果预览和后续验证共同决定。
