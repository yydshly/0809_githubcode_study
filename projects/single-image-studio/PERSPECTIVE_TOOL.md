# 垂直透视校正设计合同

## 目标与边界

本轮为本地编辑器增加一个可撤销的“垂直透视”工具，用于建筑立面、室内墙线、文档边缘和商品包装因轻微仰拍/俯拍产生的上窄下宽或上宽下窄。

- 范围固定为 `-20–+20`，整数步进；正值扩展上沿，负值扩展下沿。
- 这是对称的单轴 keystone 校正，不是自动识别、四角透视、文档扫描或镜头畸变校正。
- 为避免产生透明空边，窄侧保持覆盖画布，宽侧会超出并被对称裁掉。界面必须明确提示这一代价。
- `0` 必须沿用原渲染路径，不创建额外几何画布，保证现有结果不变。
- 校正进入统一 EditState、编辑历史、撤销、重做和重置。

## 视觉与交互合同

- 产品表面：功能型混合工作区（Functional Hybrid Workspace）。
- 控件放在“构图与方向”组，紧邻水平校正；标签直接写“垂直透视”。
- 输出值使用有符号整数，并补充“上宽 / 下宽”的人话解释。
- 提供独立归零按钮；滑动时即时预览，完成操作后才写入历史。
- 预览不能用 CSS 近似梯形。开启校正后使用 Canvas，以与导出相同的逐行映射公式绘制缩放版预览。
- 预览仍保留完整画布、裁剪框、1:1/旋转组合和 JPEG 背景语义。
- 小屏保持单列，不让新增控件挤压画面；键盘可操作原生 range 和归零按钮。

## 几何合同

设校正量为 `a`，`p = a / 100`：

- 上沿因子 `top = 1 + p`
- 下沿因子 `bottom = 1 - p`
- 覆盖缩放 `cover = 1 / min(top, bottom)`
- 第 `y` 行的宽度因子在 `top` 与 `bottom` 间线性插值，再乘 `cover`
- 每行以画布水平中心为轴绘制，输出尺寸不变

完整分辨率导出与缩放预览必须调用同一个逐行绘制函数。旋转与水平校正先执行，垂直透视随后执行，最后才裁剪、调色和缩放输出。

## 验收

- 状态：边界、舍入、历史、撤销和重置均有单测。
- 几何：正负方向、覆盖尺度、中心对称、0 值旁路均有单测。
- 渲染：非零时出现单独 perspective canvas，裁剪从该画布取样；0 值现有画布角色不变。
- 界面：滑块、归零、裁边说明、上宽/下宽显示和 Canvas 预览开关有回归测试。
- 组合：至少覆盖 `90° + 1:1 + 垂直透视`，并以项目原创倾斜工作室图片做人工浏览器复核。
- 若当前环境无法取得浏览器截图/DOM 控制证据，必须明确标为待复核，不能用 HTTP 200 或单测代替视觉结论。
