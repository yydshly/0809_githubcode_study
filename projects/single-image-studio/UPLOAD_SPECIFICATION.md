# 上传规格适配处理方案

状态：内部产品 Alpha；纯本地组合流程，不依赖模型或远程服务。

## 目标

用户一次填写内容保留方式、目标比例、最长边和文件上限，系统按固定顺序组合现有能力并生成经过核验的 JPEG。独立的裁剪、完整适配、格式转换和压缩工具继续保留。

## 第一版范围

- 提供普通上传、严格表单、小附件、完整方图和裁剪方图五个透明参数预设；选择后仍可修改。
- 完整保留：原比例或通过纯色留白适配 1:1、4:5、16:9。
- 允许裁剪：居中裁剪为 1:1、4:5 或 16:9。
- 最长边：320–2048 px。
- 文件上限：100–10240 KB。
- 输出固定 JPEG；透明区域使用用户选择的纯色。
- 最多按现有压缩合同尝试 10 档；未达标必须明确显示。
- 全程本地执行，不调用 PhotoRoom、OpenAI、MiniMax 或其他模型。
- 结果页逐项显示 JPEG、最长边、文件上限和内容保留策略的目标与实际值；只有四项全部通过才显示“全部达标”。

## 固定顺序

```text
完整保留/允许裁剪
→ 目标比例和尺寸
→ JPEG 编码
→ 目标体积压缩
→ 格式、尺寸、体积、像素和哈希重开核验
```

## 非目标

- 第一版不承诺透明 PNG 体积上限。
- 不自动识别主体或决定裁剪位置。
- 不生成画面外内容，不执行 AI 扩图。
- 不为平台规则背书；用户填写的限制才是本次目标。
