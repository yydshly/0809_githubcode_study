先学会判断，

这是一条与现有样例图库分开的新人路径。它不要求先看完 127 组效果，而是帮助你理解每个 Skill 的真实性契约、输入要求、常见失败，以及怎样完成第一次可信实验。

三条学习路径 技术路线 输入预检 失败类型 证据等级

按你现在拥有的时间开始。

新人不需要一次理解所有细节。先明确证据类型和真实性要求，再逐步进入单个 Skill 和完整实验。

15 MIN

建立方向

读四层模型、路线表，再打开三个候选 Skill 的快速卡。目标是找出真实性契约最接近任务的一条路线。

1 HOUR

完成一次对照

用同一张安全输入测试两条不同路线，例如全量重绘与保留照片证据，比较它们舍弃的信息。

1 DAY

形成可复核记录

完成三种题材、至少一个失败样本、一份数字产品预演和一条生产前检查清单。

先区分四种东西。

最常见的误解，不是审美问题，而是把不同强度的证据混在一起。

01 · SOURCE

真正输入

自摄、授权、合成或代码 fixture。必须记录来源、隐私和发送边界。

02 · EFFECT

研究结果

依据视觉规则生成或构建的结果；没有运行记录时不能冒充上游原生输出。

03 · PREVIEW

产品预演

把效果放进海报、封套、屏幕或明信片的数字语境，不代表已经生产。

04 · PROOF

生产证据

真实打印、部署、跨环境复测和验收记录；缺少它们时不能升级结论。

五条路线，回答五种问题。

不要按画风分组，而要看照片是否保留、信息如何压缩，以及最终输出由模型还是代码负责。

路线核心问题适合先看
原图保留与确定性组合哪些照片像素必须保持不变？Travel、Poetic、Relic、Photo Abstract、Postcard
编辑拼贴与多场景组织如何让照片、色块与版面形成共同叙事？Daily、Scenes Gathered
重绘与关系蒸馏舍弃多少外观信息，仍能保留记忆或结构？DYY、Scene Distillation、Photo Revival
风格与隐喻编译如何将主题压缩为色锚、点阵和版式语法？GC Minimal、Pixel
代码原生生成如何重复渲染并用指标公开通过或失败？Photo Distill

13 个 Skill，60 秒逐个理解。

展开卡片，只读“适合什么、第一次用什么、不能证明什么”。之后再决定是否进入完整本地样例。

01Daily Photo Playground＋

高饱和编辑版式、照片小窗、主体越界与连续留白。

第一次输入
单人街拍或拥有 2–3 个明显源色的日常场景。
适合
生活方式编辑页、活动视觉、社交竖版内容。
不能证明
面孔、人物数量或照片像素保真。
02DYY Photo Deconstruct＋

用剪影与最少必要记号压缩动作、主体和空间关系。

第一次输入
轮廓清楚、动作方向明确的单主体。
适合
极简动作研究、无文字艺术卡、视觉词汇训练。
不能证明
身份、动作测量、安全分析或纪实还原。
03Travel Photo Abstraction＋

锁定照片证据区，把轴线、间隔和深度转为抽象面板。

第一次输入
轴线、遮挡、间隔和纵深清楚的旅行照片。
适合
旅行编辑页、目的地叙事、照片与关系图并置。
不能证明
可以修改、衍生或再分发其严格 source-available 上游实现。
04Scenes Gathered＋

将多张真实场景通过撕纸边、色场和结构色组织成共同叙事。

第一次输入
同一地点或事件的 3–4 张连续照片。
适合
旅行日志、社区故事、季节或时间序列。
不能证明
人物连续性、商业使用权或当前上游仍能安装。
05Scene Distillation＋

完全移除照片，只保留中心张力、流向、色彩角色和情绪命题。

第一次输入
有明显流向、空白关系或中心张力的场景。
适合
概念封面、情绪海报、关系蒸馏练习。
不能证明
真实地点、人物身份或事实被保留。
06GC Minimal Zine Poster＋

将主题编译为极简隐喻、单一高彩色锚、微字与印刷质感。

第一次输入
一句短主题、一个物体或一段短文章。
适合
文化海报、文章封面、概念活动视觉。
不能证明
照片保真或模型生成文字已经可生产。
07Photo Revival＋

把照片全量重绘成小型手绘记忆，不保留原图像素。

第一次输入
主体清楚、包含 1–2 个记忆细节的旧物或家庭场景。
适合
个人记忆卡、非纪实家庭叙事、旧物故事。
不能证明
照片修复、年代鉴定、面孔或身份还原。
08Pixel Style Poster＋

用细密点阵、网频、方向性线条和有限套色编码人物与材质层级。

第一次输入
材质差异明显的人物近景或三主体静物。
适合
音乐封套、文化海报、材料语言教学。
不能证明
8-bit 游戏像素、身份保真或真实网印结果。
09Photo Relic Editorial＋

上区锁定真实照片，下区将结构与记忆压缩成单一 relic。

第一次输入
有明确结构、色锚和可抽象遗物的照片。
适合
地方记忆、工艺故事、照片证据与版画并置。
不能证明
照片区被生成模型重画后仍然像素保真。
10Photo Distill＋

用 HTML、CSS、SVG 与量化指标实现代码原生关系蒸馏。

第一次输入
轴线、重心、色锚和间隔容易提取的图像。
适合
可重复海报、参数化系列、缩略可见性与着墨率研究。
不能证明
上游代码有完整许可证或跨浏览器像素绝对一致。
11Poetic Line Zine Poster＋

保留照片并用诗性线条、色彩路径和确定性标题完成下方面板。

第一次输入
动作路径、风势或移动节奏明显的场景。
适合
诗性活动海报、人物故事、表演与旅行编辑页。
不能证明
本地人工 75 分门槛是上游官方标准。
12Photo Abstract Editorial＋

保留照片证据，同时将轮廓理解转向轴线、间隔、遮挡和重心。

第一次输入
建筑、交通或工作室等结构丰富场景。
适合
建筑编辑、城市关系图、空间观察练习。
不能证明
工艺安全判断或没有参与者的盲测已经有效。
13Photo-to-Zine Postcard＋

把照片转为固定 2:3 的正反面明信片系统，包含色卡与功能区。

第一次输入
构图完整、可取三色、具有旅行叙事的照片。
适合
旅行纪念、展览周边、系列化双面纸品。
不能证明
实体印刷、邮政合规或真实寄送。

生成前，先做输入预检。

任意一个问题没有答案，都应该先停止生成，而不是靠结果碰运气。

  • 我能合法使用，并向所需模型发送这张图片吗？
  • 主体数量是否清楚；是否要求一个人都不能丢？
  • 哪些像素必须保持不变，哪些内容允许重绘？
  • 是否包含证件、人脸、地址、GPS、未成年人或客户机密？
  • 输入是否有可提取的轴线、重心、色彩角色或记忆细节？
  • 目标画幅是什么；必须完整展示还是允许裁切？
  • 最终用途是概念探索、数字版面、实体印刷还是实际部署？

失败不是丑，而是契约没成立。

新人最需要积累的是失败类型，而不是只收藏成功图片。

COUNT

人数丢失

五人输入变成四人。材料语言可能成立，但人物数量契约失败。

FIDELITY

证据区被重画

声称保留原照，实际照片区域由模型重新生成，不能标记像素保真。

FRAME

完整画面被裁切

页面看起来更满，但 SOURCE 或 EFFECT 边缘的重要事实消失。

TYPE

伪文字进入成品

不可读标题被当成活动信息。真实文字必须由确定性排版层负责。

ABSTRACTION

抽象过度或不足

漂亮但无法追溯输入，或只是滤镜化原图，都没有证明信息选择能力。

PRODUCTION

预演冒充落地

CSS mockup 不是已经印刷、投放、部署或被客户采用的证据。

第一次可信实验，只做六步。

不要同时混用多个 Skill。一次实验只回答一个可推翻的问题。

  1. 选择一张自摄或明确授权、没有敏感信息的图片。
  2. 写 Scene Card：主体、空间关系、三种源色、必须保留项、允许舍弃项。
  3. 只选一个 Skill，不复制权利不清的上游参考资产。
  4. 保存完整 SOURCE、完整 EFFECT、提示或参数、环境版本和时间。
  5. 按人数、裁切、原照保真、文字、画幅和任务目标逐项检查。
  6. 写下证明了什么、没有证明什么，以及下一次什么结果会推翻当前结论。

证据从 E0 到 E5，不是审美评分。

级别表示能够支持多强的结论，不表示画面是否更漂亮。

E0

目录线索：知道某个仓库或 Skill 值得定位。

E1

固定上游证据：知道特定 commit 声明或展示了什么。

E2

本地概念效果：视觉语法值得继续验证。

E3

受控配对：限定输入与条件下观察到具体取舍。

E4

产品数字预演：知道可能进入怎样的真实载体。

E5

生产验证：真实打印、部署、跨环境和验收记录。
