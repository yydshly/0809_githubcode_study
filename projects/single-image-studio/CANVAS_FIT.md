# 完整图片适配 / 加留白体验契约

状态：内部产品 Alpha；本地单图能力。

## 设计契约

- Entry mode：revision-led feature implementation。
- Target user：需要把整张图片放进方形、竖版或横版画布，但不希望主体或边缘被裁掉的普通用户。
- Desired first impression：与“裁剪填满”明确相反——完整显示图片，再用留白适配目标比例。
- Visual ambition：Functional。
- Experience architecture：Editorial Flow。
- Primary journey：上传图片 → 选择“完整图片适配” → 选择画布比例、最长边、四周留白和底色 → 预览完整图片位置 → 本地生成并重开核验 → 对比与下载。
- Autonomy authorization：用户确认前一功能并要求继续扩展，可直接完成可逆的本地产品改动。
- User-decision boundary：用户决定画布比例、尺寸、留白和底色；系统不裁切、不放大小图、不生成画面外内容。

## 能力边界

- 默认保持原图比例，并提供方形 1:1、竖版 4:5、横版 16:9 与自定义宽高比例；因此长图不需要先塞进三个固定模板。最长边为 320–2048 px。
- 输入图片始终按 `contain` 放入画布中心；0%–25% 留白只缩小图片在画布内的占用，不裁切来源。
- 白、黑、自定义底色输出 JPEG；透明画布输出 PNG。
- 小图不会被放大，因此在大画布上可能出现更多留白或透明区域。
- 这不是 AI 扩图：不会补画天空、背景、人物或物体，也不会识别主体或自动重新构图。
- 输出复用现有 renderer 的来源归一化，并执行独立格式、尺寸、像素、metadata 与哈希重开检查。

## 验收覆盖

| 状态 | 验收标准 |
| --- | --- |
| 入口 | 明确“完整显示、不裁切”和“不是 AI 扩图” |
| 设置 | 原图比例为默认；固定 / 自定义比例、尺寸、留白、底色均有边界和可见反馈，留白滑块与数字初始值一致 |
| 预览 | 画布比例、底色与图片完整占位随设置变化 |
| 结果 | 输出尺寸与设置一致，显示画布、留白、格式和未放大边界 |
| 下载 | JPEG / PNG 与当前任务、结果哈希和 Alpha 策略绑定 |
| 窄屏 | 控件单列，预览和结果无横向溢出 |
