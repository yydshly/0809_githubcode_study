# 研究场次记录

> **当前状态**：用户研究已后置，本目录没有已执行场次。只有获得真实对象并完成授权后才新增 `SESSION-*`。

本目录只保存 Visual Route Studio 自己的访谈、卡片测试与原型测试记录。公开二手证据继续保存在 [`PUBLIC_EVIDENCE_SCAN.md`](../PUBLIC_EVIDENCE_SCAN.md)。

## 文件类型

- `PILOT-*`：不计入研究结果的试访或主持演练，只用于修订问题、卡片和原型流程。
- `SESSION-*`：符合招募条件、已取得记录同意的真实参与者场次。
- `SYNTHESIS-*`：跨场归纳；每条结论必须能回指场次和证据指针。

## 证据边界

- 试访不升级 H1–H6，也不计入 6–8 场正式样本。
- 不以虚构人物、模拟回答或研究员猜测代替用户证据。
- 每条正式观察使用 `QUOTE`、`REPORT`、`BEHAVIOR`、`ARTIFACT`、`COUNTER` 或 `INTERPRETATION` 标记。
- `INTERPRETATION` 不能单独支持结论；必须附至少一个可回查的非解释证据。
- 记录只使用参与者代号和脱敏任务；不保存真实姓名、客户名、联系方式、未授权图片或录音链接。
- 参与者撤回授权时，从汇总中移除对应证据指针，并在场次文件记录撤回状态。

## 状态约定

| 状态 | 含义 |
| --- | --- |
| `prepared` | 材料已准备，尚未开始 |
| `completed-pilot` | 试访已完成，只能用于改研究工具 |
| `completed-D1` | 正式真实任务访谈完成，可形成 D1 证据 |
| `completed-D2` | 参与者完成交互原型任务，可形成 D2 证据 |
| `excluded` | 不符合筛选或场次失效，不进入汇总 |
| `withdrawn` | 参与者撤回授权，证据不可继续使用 |
