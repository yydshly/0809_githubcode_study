# 十二张代表性成品目标卡

> 状态：目标广度探索 D0。统一测试输入为 [“雨停以前”六张合成原图](samples/rainy-bookstore/source-contact-sheet.png)。目标卡用于比较成品，不代表需求、市场或 MVP 已确定。

## 1. 为什么使用同一组原图

如果每个目标使用不同图片，就无法判断差异来自原图还是来自成品目标。当前统一使用六张雨夜旧书店照片，只比较：

- 最终拿到的东西是否真的不同；
- 原图能否自然支持这个结果；
- 用户还必须补充哪些真实信息；
- AI 可以直接推荐，还是只能在用户明确提出后执行。

这组原图包含场景、人物背影、手部动作、室内空间、物件特写和事件顺序，足以覆盖单图、多图、连续叙事、材料提取与多尺寸适配。

## 2. 推荐权限

| 等级 | 含义 |
| --- | --- |
| 直接推荐 | 仅根据原图即可合理展示该成品的无字预览；最终文字仍由用户确认 |
| 条件推荐 | 原图在视觉上适合，但必须先知道用途、场地或规格 |
| 仅用户指定 | 图片本身无法证明用户需要该成品，不能把它作为默认推荐 |

## 4. 十二张目标卡

### T01｜文章 / 专栏封面

**用户拿到：** 一张桌面网页文章头图，以及对应的分享缩略图。

**为什么适合：** P01 的雨夜店面有清晰视觉锚点与暗部留白；P05 的旧书与压叶可以成为第二视觉层。

**默认保留：** P01 店面、雨夜和暖光保持为真实照片，不新增店名、人物或事件。

**三个方向：**

1. 完整店面原图主导；
2. 店面与压叶的编辑并置；
3. 暖门、雨线与叶形组成单一隐喻。

**输出：** 1600×900 头图、1200×630 分享图、无字底图与真实排字版。

### T02｜展览海报

**用户拿到：** 一张可印刷海报和一张展厅入口屏适配图。

**为什么适合：** 深雨蓝、琥珀灯光与青绿雨伞形成远距离可识别的主视觉。

**必须等待：** 用户提供真实展览名称、日期、地点和主办信息。没有这些信息只能预览，不能形成成品。

**三个方向：**

1. 摄影海报：P01 大幅原照；
2. 编辑海报：P01、P05 双图结构；
3. 抽象海报：门框、雨线、叶形与伞迹。

**输出：** A2 印刷版、1080×1920 入口屏、无字底图与真实排字版。

### T03｜图片轮播组

**用户拿到：** 一组可以连续阅读的 6–8 张 4:5 图片卡。

**为什么适合：** 六张照片本身已有开门、进入、浏览、发现、离开的时间顺序。

**默认保留：** P02、P04、P06 原样；不改变人物数量、动作和事件顺序。

**三个方向：**

1. 时间顺序：每张照片一张卡；
2. 场景节奏：室外、门槛、室内、物件、离开；
3. 证据与记忆交替：真实照片卡穿插材料 / 抽象过场。

**输出：** 6–8 张 1080×1350 图片、封面卡、无字层与真实文字层。

### T04｜六页视觉小志

**用户拿到：** 一套有封面、开场、展开、转折、过场和收束的连续作品。

**为什么适合：** 原图数量与事件完整度恰好支持一条六页叙事。

**默认保留：** 页面顺序与必须原样照片锁定；重绘页必须明确标注为转译。

**三个方向：**

1. 现场叙事；
2. 记忆叙事；
3. 原图和重绘各半的混合叙事。

**输出：** 封面、六张 4:5 页面、PDF、分享缩略图。

### T05｜明信片系列

**用户拿到：** 三至六张正反面明信片，可以单张分享或组成小套装。

**为什么适合：** 店外、开门双手、书店内景、旧书压叶和离开都能独立成为一张卡。

**默认保留：** 正面优先保留完整原照；背面文字区由确定性排版完成。

**三个方向：**

1. 摄影明信片；
2. 原照与纸张遗迹并置；
3. 限色 / 半色调收藏卡。

**输出：** 3–6 张 2:3 正反面图片、系列封面卡、印刷安全区版本。

### T06｜滚动摄影故事页

**用户拿到：** 一条只针对电脑网页的纵向滚动故事。

**为什么适合：** 六张照片既有远景、近景，也有连续动作和可作为章节锚点的物件。

**默认保留：** 原图按时间顺序出现；网页动画不能制造原图中不存在的动作或身份。

**三个方向：**

1. 大幅照片沉浸滚动；
2. 杂志式图文段落；
3. 档案式照片窗与时间标记。

**输出：** 桌面网页 Hero、六个滚动章节、分享图；不制作手机和平板版本。

### T07｜展厅 / 展会屏幕

**用户拿到：** 适配指定大屏比例的一组静态或缓慢切换画面。

**为什么适合：** P01 和 P06 的深色远景适合宽屏；P02 与 P05 可以作为近景插入。

**必须等待：** 用户提供屏幕比例、分辨率、观看距离、是否循环和真实标题。

**三个方向：**

1. 单幅电影式宽屏；
2. 三联照片屏；
3. 雨线、门槛和叶形的低速抽象序列。

**输出：** 指定宽屏 / 竖屏画面、静态兜底图、真实排字安全区版本。

### T08｜包装纸

**用户拿到：** 从原图元素提炼出的可重复纹样，而不是把照片直接平铺。

**为什么适合：** P05 压叶、P01 雨线、青绿色雨伞和书脊提供四类可辨识图形来源。

**默认保留：** 不要求保留完整照片，但需要记录每个图案元素来自哪张原图。

**三个方向：**

1. 压叶稀疏纹样；
2. 雨线、门框与伞迹的几何纹样；
3. 书脊和纸张纹理的限色拼版。

**输出：** 无缝重复单元、整张包装纸预览、三种来源色配色。

### T09｜演示文稿视觉套页

**用户拿到：** 封面、章节过场和收尾页，而不是替用户编写整份演示内容。

**为什么不能直接推荐：** 一组照片无法说明用户要演示什么、面对谁、希望达成什么结果。

**必须等待：** 用户主动选择该目标，并提供演示目的、章节结构和真实文字。

**三个方向：**

1. 全幅照片章节页；
2. 照片证据窗加内容区；
3. 从照片关系提炼的抽象过场页。

**输出：** 16:9 封面、章节页、收尾页图片底稿；不自动生成商业结论。

### T10｜构图讲解海报

**用户拿到：** 一张展示原图、构图标注与可验证结论的教学海报。

**为什么适合：** 六张图包含建筑对称、手部特写、纵深透视、背影视线、物件焦点和远近关系。

**必须等待：** 用户选择教学主题，例如“视觉动线”“冷暖对比”或“叙事镜头顺序”。

**三个方向：**

1. 单图构图线标注；
2. 六图对比矩阵；
3. 原图与关系抽象图并置。

**输出：** A2 教学海报、16:9 讲解页、无标注原图对照版。

### T11｜照片遗迹卡

**用户拿到：** 一张同时显示原始照片证据与材料化转译的纪念 / 档案卡。

**为什么适合：** 旧书、压叶、木材、雨水和灯光天然支持纸张、印刷与收藏材料语言。

**默认保留：** 至少保留一个可追溯的原照窗口；材料化效果不能伪装成历史原件。

**三个方向：**

1. 原照加档案登记线；
2. 纸张、压印与磨损材料层；
3. 原照与炭笔 / 水洗重绘并置。

**输出：** 2:3 正反面卡、原图对照图、来源说明区。

### T12｜活动发布包

**用户拿到：** 同一视觉语言下的海报、社交卡、屏幕和票券，而不是四张互不相关的图。

**为什么不能直接推荐：** 原图只能提供视觉素材，不能证明存在活动，更不能生成活动名称、日期、地点或票务事实。

**必须等待：** 用户主动提出活动目标并提供完整真实信息和渠道规格。

**三个方向：**

1. P01 店面照片作为统一主视觉；
2. P05 压叶作为跨载体核心符号；
3. 雨线、门槛、伞迹组成可扩展图形系统。

**输出：** A2 海报、4:5 社交卡、16:9 屏幕、2:1 票券及统一无字底图。

## 5. 从十二张卡得到的产品规则

### 规则一：原图只能决定适配度，不能决定真实用途

系统可以判断照片适合封面、轮播或小志，但不能凭一张店面照片推断用户正在举办展览或活动。

### 规则二：推荐必须分层

- 首屏直接推荐 T01、T03、T04、T05、T06、T11。
- 用户补充用途后再展示 T02、T07、T08、T10。
- T09、T12 只在用户主动选择或明确描述时出现。

### 规则三：用户首先比较成品，不比较技术

每张目标卡先展示成品预览、数量和使用位置，再提供三种改造方向。Skill、模型和 Prompt 始终留在后台。

### 规则四：缺少事实时可以预览，但不能假装完成

没有标题时可以显示无字封面；没有活动日期时可以预览海报结构；但导出前必须补齐真实文字和规格。

### 规则五：多成品系统不是默认首选

发布包的价值高，但输入要求和失败成本也高。它应从用户明确目标进入，而不是仅凭图片自动推荐。

## 6. 当前结论

十二张卡证明目标空间可以被分成三层：

1. **从原图即可推荐的图片成品**：封面、轮播、小志、明信片、滚动故事、遗迹卡。
2. **需要补充用途才能推荐的场景成品**：海报、空间屏幕、包装纸、教学海报。
3. **必须由用户主动提出的任务型成品**：演示套页、活动发布包。

这比“系统自动猜一个目标”更可靠，也比一次展示 96 个入口更容易理解。下一步的桌面网页探索应围绕这三层，而不是围绕十三个 Skill 或自由画布组织。
