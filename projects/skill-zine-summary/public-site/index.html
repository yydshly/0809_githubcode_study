先看技术路线，再看漂亮结果。

研究不做综合排名。不同 Skill 解决的问题不同：有的保护照片像素，有的允许记忆式重绘，有的只保留关系与节奏，还有的追求代码原生与可重复验证。

Route 01

原图保留与确定性组合

把照片当作不可替换的证据区域，再由生成面板、排版或产品结构完成扩展。

Route 02

重绘、蒸馏与材料化

允许重新解释主体，通过留白、点阵、剪影、色锚或记忆性笔触压缩信息。

Route 03

代码原生与量化检查

使用 HTML、CSS、SVG 与像素指标，让输出可以重复渲染并公开通过或失败条件。

这是什么证据，必须说清楚。

  1. 上游官方样例、本地概念效果和确定性代码实验分别标记，不互相冒充。
  2. 127 组 SOURCE → EFFECT 是本地研究数量，不是成功率，也不是 13 个 Skill 的质量排名。
  3. 数字产品预演不代表完成实体印刷、真实投放、客户项目或现场部署。
  4. 公开站点不携带权利未清的上游图片；完整实验证据继续在本地研究环境中核对。
