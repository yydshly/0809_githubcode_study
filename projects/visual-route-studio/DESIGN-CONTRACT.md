# 原型设计契约

> **历史资产（2026-08-11）**：本契约对应已停止的“路线决策顾问”方向。原型和验证记录继续保留，但不代表当前 [StoryFold](README.md) 的照片故事生成流程或 MVP 范围。

## 当前请求

- Entry mode：brief-led / greenfield prototype
- Request revision：1
- 直接授权：用户要求“继续”，此前已确认独立子项目与产品方向，可直接执行可逆的文档和前端原型工作。

## 产品与用户

- 目标用户：独立设计师、摄影师、内容创作者、小型品牌与文化团队。
- 使用情境：用户有一组原始素材和真实交付任务，但不确定应保留、重绘、蒸馏或材料化。
- 第一印象：这是一个冷静、可信、能帮助作决定的工作台，而不是风格图库或生成模型市场。
- 视觉野心：Functional with editorial hierarchy。
- 体验架构：Editorial Flow。

## 约束

- 只支持中文与单一浅色主题。
- 使用原生 HTML、CSS 和 JavaScript，不引入依赖、后端、账号或真实模型调用。
- 原型自身包含三项虚构任务和代码原生示意，不复制前置研究图片或第三方资产。
- 页面必须在桌面、平板和 390px 手机保持可读、无横向溢出。
- 所有交互可由键盘访问，并提供清晰焦点状态。
- 不使用裁切来掩盖 SOURCE 或 EFFECT。
- reduced-motion 下取消非必要平滑滚动和过渡。

## 主要旅程

1. 从三个任务中选择一个。
2. 阅读任务事实、保真要求和三条路线建议。
3. 选择路线并查看完整 SOURCE / EFFECT 示意与保留、损失、风险。
4. 在海报、专题头图、卡片三种载体中切换产品预演。
5. 导出当前任务的创意简报文本。

## 本轮交付物

- 五类路线研究卡片。
- 用户访谈提纲。
- 三个任务的可运行决策原型。
- 桌面、平板和手机验证记录。
- 独立运行说明和后续研究边界。

## 不在本轮范围

- 真实素材上传、文件存储和账号系统。
- 实际图像生成或第三方 Skill 调用。
- 印刷文件、实体打样或真实客户交付。
- 暗色主题、多语言和团队协作。
- 将旧研究站代码或资产复制进本项目。

## 可观察完成标准

- 入口明确说明产品解决“如何选择路线”，而不是“生成更多图片”。
- 三个任务均有独立事实、三条路线、对比结论和产品去向。
- 路线切换会更新 EFFECT、能力说明、风险和适用载体。
- 载体切换会改变应用画布而非只改按钮状态。
- 简报导出包含任务、不可改变事实、选定路线、保留、损失、风险和下一步。
- 页面在 1440、900 和 390 宽度完成主要旅程。
- Tab 焦点顺序合理、焦点可见；无鼠标也能完成主要旅程。
