# Skill Zine 新人学习指南

这份指南负责回答一个与样例图库不同的问题：**第一次接触这些 Skill 时，应该先理解什么、怎样选择输入、如何判断失败，以及如何完成第一轮可信实验。**

公开网页入口：<https://yydshly.github.io/0809_githubcode_study/start/>

完整图片实验仍在本地研究站中查看；公开新人页不复制上游样例，也不把本地概念效果冒充上游实际运行结果。

## 先建立四层心智模型

1. **SOURCE**：真实提供给实验的输入。它可能是自摄、合成或代码 fixture，必须说明来源。
2. **EFFECT**：按照某个 Skill 的高层视觉规则制作的结果。除非有运行记录，否则不能称为上游原生输出。
3. **PRODUCT PREVIEW**：把 EFFECT 放进海报、明信片、屏幕、封套或展览环境的数字预演，不等于已经生产。
4. **PRODUCTION EVIDENCE**：真实打印、部署、跨浏览器、现场使用或验收记录。没有这些证据时，结论保持在概念或数字预演层。

## 13 个 Skill 的第一次理解

| Skill | 最适合先研究 | 第一次输入建议 | 不应据此声称 |
| --- | --- | --- | --- |
| Daily Photo Playground | 高饱和编辑版式、照片小窗、主体越界 | 单人街拍或具有 2–3 个明显源色的日常场景 | 面孔或照片像素保真 |
| DYY Photo Deconstruct | 剪影与最少必要记号 | 轮廓清楚、动作明确的单主体 | 身份、动作测量或纪实还原 |
| Travel Photo Abstraction | 锁定照片区与关系面板 | 轴线、间隔和深度明确的旅行照片 | 可以修改、衍生或再分发上游实现 |
| Scenes Gathered | 多场景照片的共同色与结构连接 | 同一地点或事件的 3–4 张连续照片 | 人物连续性、商业用途或当前上游仍可安装 |
| Scene Distillation | 移除照片后的情绪和关系蒸馏 | 具有中心张力、流向或空白关系的场景 | 真实地点、人物身份或事实保留 |
| GC Minimal Zine Poster | 主题到隐喻、色锚与版式的 prompt compiler | 一句短主题、物体或短文章 | 照片保真或文字排版已经可生产 |
| Photo Revival | 记忆式全量重绘 | 主体清楚、包含 1–2 个记忆细节的旧物或家庭场景 | 照片修复、年代鉴定或身份还原 |
| Pixel Style Poster | 细密点阵、半调层级和套色关系 | 材质差异明显的人物近景或静物 | 8-bit 像素画、真实网印或身份保真 |
| Photo Relic Editorial | 原照证据与单一记忆遗物的双区版式 | 有明确结构、色锚和可抽象遗物的照片 | 上区照片被重画后仍叫像素保真 |
| Photo Distill | HTML/CSS/SVG、参数化与量化 QA | 轴线、重心、色锚和间隔容易提取的图像 | 上游代码许可、跨浏览器像素绝对一致 |
| Poetic Line Zine Poster | 原照、诗性线条与确定性标题组合 | 动作路径或风势明显的场景 | 本地 75 分是上游官方标准 |
| Photo Abstract Editorial | 从物体轮廓转向轴线、间隔和遮挡关系 | 建筑、交通或工作室等结构丰富场景 | 工艺分析、安全判断或读者盲测已经有效 |
| Photo-to-Zine Postcard | 2:3 双面产品、色卡与功能背面 | 构图完整、可取三色、具有旅行叙事的照片 | 实体印刷、邮政合规或真实寄送 |

## 输入图片预检

在运行任何 Skill 前，先回答：

- 我能否合法使用并向所需模型发送这张图片？
- 主体数量是否清楚，是否必须一人不丢？
- 哪些内容必须保持像素不变，哪些允许重绘？
- 是否存在证件、人脸、住址、GPS、未成年人或客户机密？
- 输入是否有可提取的轴线、重心、色彩角色或记忆细节？
- 目标画幅是什么；原图完整展示还是允许裁切？
- 最终用途是概念探索、数字版面、实体印刷还是实际部署？

任一问题没有答案时，先不要生成。

## 新人最需要看的失败类型

1. **人数丢失**：五人输入变成四人。风格成立，但数量保真失败。
2. **证据区被重画**：声称保留原照，结果却由模型重新绘制照片区域。
3. **完整图被裁切**：页面看起来更满，但 SOURCE 或 EFFECT 的边缘事实丢失。
4. **伪文字进入成品**：图像模型生成不可读标题，却被当成活动信息使用。
5. **抽象过度**：视觉漂亮，但无法从输入追溯任何轴线、间隔或色彩角色。
6. **抽象不足**：只是给原图加滤镜，没有证明 Skill 的信息压缩方式。
7. **数字预演冒充生产**：把 CSS mockup 描述成已经印刷、投放或客户采用。

## 第一次可信实验

1. 选择一张自摄或明确授权、无敏感信息的图片。
2. 写一张 Scene Card：主体、空间关系、三种源色、必须保留项、允许舍弃项。
3. 只选一个 Skill，不混用多个上游提示或参考资产。
4. 保存完整 SOURCE、完整 EFFECT、提示／参数、环境版本和时间。
5. 按人数、裁切、原照保真、文字、画幅和任务目标逐项检查。
6. 写下“证明了什么、没有证明什么、下一次如何推翻当前结论”。

## 三条学习路径

### 15 分钟：建立方向

阅读本指南的心智模型、路线表和三个候选 Skill 的快速卡。目标不是选择最好看的，而是找出真实性契约最接近任务的一条路线。

### 1 小时：完成第一次对照

用同一张安全输入测试两条不同路线，例如 Photo Revival 与 Photo Relic；比较“完全重绘”和“保留照片证据”的差异。

### 1 天：形成可复核记录

选择一个 Skill，完成三张不同题材输入、至少一张失败结果、一份产品数字预演和一条生产前检查清单，并用实验记录模板保存证据。
