# 场景技能层设计合同

## 设计合同

```text
Entry mode: revision-led
Request revision: 6
Target user and context: 已上传一张图片、知道想得到什么用途，但不理解裁剪、Alpha、画布和导出参数的普通用户
Desired first impression: 先看懂哪些是本地基础、远程抠图或生成式能力，再选择“我要做什么”，随后仍能检查和微调每一步
Visual ambition: Functional
Experience architecture: Editorial Flow
Visual constraints: 沿用现有任务卡、工作预览、设置卡和结果工作台；场景优先于自由工具，不新增装饰性页面
Information constraints: 明确本地/远程、是否依赖服务、会改变什么、输出什么；不得声称证件合规或 AI 自动质量判断
Operation constraints: 复用现有 EditState、renderer、BackgroundRemovalProvider、蒙版修正和下载合同；商品交付布局只在修边后本地运行且不改变蒙版；老照片基础整理使用本地 renderer，AI 老照片实验才使用既有 OpenAI image edit route 和固定提示词白名单
State constraints: 服务未配置时远程场景必须不可选；失败不覆盖来源、不自动重试；换处理方向保留当前图片并退休旧结果
Environment constraints: 当前首轮桌面 Chromium；移动与正式发布不在本次范围
Primary journey: 上传并确认图片 → 选择实际用途 → 自动载入场景起点 → 用户微调 → 生成、检查和下载
User-defined phases: 场景技能框架；隐私友好分享副本；商品白底图；报名照/底色头像；社交头像与封面；社交九宫格切图；老照片本地基础整理；独立 AI 修复实验；工程与浏览器验收
Required artifacts: scenario-skills.js、social-card-overlay.js、social-grid-split.js、动态能力层级总览、场景优先任务选择、五条场景设置与结果合同、独立 AI 老照片固定提示词合同、测试、状态文档
Autonomy authorization: 用户已明确“确定”，授权在既有产品边界内直接实现
User-decision boundary: 新外部服务、机构证件合规承诺、真实计费老照片调用、批量/账号/正式发布不在本次授权内
Observable completion criteria: 八个场景以用户用途出现；场景默认参数进入各自 renderer/provider；隐私分享、九宫格和本地老照片任务无需 API；AI 老照片任务明确生成风险且服务端拒绝任意提示词；商品白底支持本地大小/留白/位置/柔和阴影并导出不透明 JPEG；无服务时只关闭远程场景和 AI 实验
```

## 场景与边界

| 场景技能 | 复用路径 | 默认起点 | 当前承诺 |
| --- | --- | --- | --- |
| 隐私友好分享副本 | metadata 输出政策 → 完整比例 → JPEG → 尺寸 / 体积限制 → 重开 / hash | 1600 px、≤ 1 MB、白底 JPEG | 清理文件 EXIF / GPS / XMP / IPTC / comment；不识别人脸、地址、车牌或画面文字，不声称完全匿名 |
| 商品白底图 | 本地构图 → 远程抠图 → 本地修边 → Alpha 主体边界 → 一套留白 / 位置 / 阴影 → 四规格白底 JPEG / ZIP | 通用方形 1200 × 1200、86% 主体大小、居中、无阴影；同步派生竖版 1200 × 1500、横版 1200 × 900 与当前像素 | 制作一张来源图的通用商品交付套装；不会重复调用 Provider，不代表平台规则，也不是多来源批处理 |
| 报名照 / 底色头像 | 本地头肩构图 → 远程抠图 → 本地修边/选底 → 人物大小/上下位置 → 六规格 / 单张 / ZIP / 六宫格下载 | 600 × 600 方形起点；六规格为两种通用像素 × 白 / 蓝 / 暖红；六宫格为 1800 × 1200 | 普通报名和头像用途；手动构图不做自动人脸定位，通用模板不承诺护照、签证、物理冲印尺寸或机构受理 |
| 社交头像与封面 | 完全本地的比例 / 尺寸模板，可选短标题与通用安全区；一次派生四规格 / ZIP | 1:1、最长边 1080；标题为空 | 同一图片与标题派生方形、竖版、横版封面和竖屏故事；最多 40 字 / 两行，可选上下位置、对齐和明暗；标题写入下载像素，不冒充平台永久规范 |
| 社交九宫格切图 | 完全本地的方形裁剪 → 3 × 3 拆分 → 单张 / ZIP | 1:1、最长边 1080、居中裁剪 | 按左到右、从上到下生成 9 张等大 PNG；先看整图再看单格；不识别主体、不补画、不自动发布，不冒充平台规则；原图限制与适用场景见 [SOCIAL_GRID_GUIDE.md](SOCIAL_GRID_GUIDE.md) |
| 老照片基础整理 | 本地五参数预设 → 裁剪/旋转/手调 → 四版本比较 → 单张/ZIP | 褪色修正，可切黑白层次、柔和降噪或保持原貌 | 同一几何与格式生成更易比较的本地副本；轻度降噪只平滑小颗粒，清晰度只增强已有反差；不识别划痕、不恢复失焦、不修脸或补全细节 |

老照片场景的主路径现在是确定性的本地基础整理，不依赖图片 API。生成式 `CR-RESTORE` 是任务页“创意生成”中的独立实验，不是这个场景的隐式下一步；它仍不提供档案复原、法证恢复或自动真伪判断。若真实夹具显示人物、文字或物件漂移不可接受，应关闭 AI 实验，而不是影响本地路径或放宽文案。
