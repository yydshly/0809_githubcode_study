# PILOT-01：阶段 0 首场试访包

## 状态与边界

- **状态**：`paused`
- **是否已执行**：否
- **是否计入正式样本**：否
- **当前证据等级**：D0
- **用途**：检查主持问题是否诱导、路线卡信息是否过载、原型旅程是否可以在不解释界面的情况下完成。

本文件不包含虚构回答或模拟结论。完成真实试访后，只记录实际发生的行为、原话、材料和主持问题。

## 试访对象

优先邀请一位符合以下条件的人：

- 独立设计师或小型文化 / 品牌团队视觉负责人。
- 最近 6 个月完成过一个海报、专题头图、封面或社交系列任务。
- 参与过视觉方向选择或批准，而不只是按既定稿执行。
- 最好经历过多尺寸适配、真实文字排版或设计交接。
- 可以口述一个脱敏任务；无需提供客户文件。

如果参与者无法还原任何最近完成的真实任务，本场只可作为主持演练并标为 `excluded`，不能把假想回答写入证据账本。

## 本场只验证什么

1. 参与者能否在没有产品术语提示时讲清任务、选择节点、变化后果与返工。
2. 五张盲测卡是否能够被复述、分组和用于排除，而不是只被评价“好看”。
3. 参与者能否在原型中独立完成任务、路线、完整对比、载体和导出旅程。
4. “保留、损失、风险、进入生产”是否被实际用于判断。
5. 主持流程能否在 55 分钟内完成。

本场不验证商业需求、付费意愿、真实生成质量、五类路线已成立或产品已达到 D1/D2。

## 会前材料

- 打开 [`INTERVIEW_GUIDE.md`](../INTERVIEW_GUIDE.md)，主持时以本文件的精简顺序为准。
- 准备 [`ROUTE_CARDS.md`](../ROUTE_CARDS.md) 的盲测字段；隐藏路线名、适合、不适合和研究员备注。
- 使用固定随机顺序：`E → C → A → D → B`。只在场后记录中保存代码映射，不向参与者解释顺序含义。
- 启动 `prototype/`，默认停留在页面顶部，不预先选给参与者看某条路线。
- 准备计时器和一份本文件副本。
- 确认是否允许匿名笔记、短句引用、录音或录屏；每项单独确认。

## 主持流程（55 分钟）

### 0–4 分钟：开场与同意

主持词：

> 今天测试的是研究问题、卡片和原型，不是你的设计能力。请尽量从最近真实完成的任务出发；敏感信息可以省略或改名。你可以随时跳过问题。过程中我会尽量不解释界面，请边操作边说你在找什么。

记录：

| 项目 | 结果 |
| --- | --- |
| 匿名笔记 | 同意 / 不同意 |
| 短句引用 | 同意 / 不同意 |
| 录音 | 同意 / 不同意 |
| 录屏 | 同意 / 不同意 |
| 不可保存内容 |  |

### 4–19 分钟：还原最近真实任务

只从这一问开始：

> 请选一个最近 6 个月已经交付、而且你参与过方向选择的视觉任务，从收到任务那一刻讲到最终交付。

只在参与者自然停顿后使用中性追问：

- 当时有哪些输入？后来又补了什么？
- 第一个需要作决定的时刻是什么？
- 实际考虑过哪些方向？谁提出、谁排除、依据是什么？
- 如果画面里的某些内容变化，会发生什么后果？
- 哪些内容当时可以自由变化？
- 第一次返工发生在哪里？谁发现了问题？
- 最终交给谁？接手者又补问了什么？

主持人不得主动说“保真”“路线过载”“不可改变事实”或五类路线名称。

### 19–32 分钟：盲测路线卡

1. 按 `E → C → A → D → B` 展示五张盲测卡。
2. 请参与者逐张用自己的话复述；不纠正。
3. 请其自由分组并为每组命名。
4. 回到刚才的真实任务，请其保留最多三张并排除其余卡片。
5. 追问：“你依据任务中的哪一处信息？”
6. 询问哪两张最难区分、哪张信息太多、是否存在都不合适的任务。
7. 最后才展示暂定名称，记录名称让理解变清楚、中性或更差。

盲测阶段只记录理解与行为，不展示原型中的效果示意。

### 32–47 分钟：决策原型任务

给出任务，不告诉参与者正确路线：

> 请使用这个原型，为“城市旅行专题”选择你认为可继续推进的路线。你需要检查完整输入和效果，换一个产品载体，最后找到可以交给下一位设计师的内容。完成时请告诉我。

主持人只可回答操作性阻塞，例如页面未加载；不能解释标签含义或推荐逻辑。

记录以下行为：

| 行为 | 时间 / 结果 |
| --- | --- |
| 首次点击 |  |
| 首次查看路线解释 |  |
| 首次查看完整 SOURCE / EFFECT |  |
| 是否打开“保留” | 是 / 否 |
| 是否打开“损失” | 是 / 否 |
| 是否打开“风险” | 是 / 否 |
| 是否主动切换路线 | 次数： |
| 是否主动切换载体 | 次数： |
| 载体预演是否引发改选或补充约束 | 行为 / 原话： |
| 是否找到导出 | 是 / 否 |
| 完成时间 |  |
| 请求主持人解释 | 次数与问题： |

### 47–52 分钟：无生成价值与交接边界

- 如果导出包只有这份决策记录和制作清单，没有新生成图片，你下一步会怎么做？
- 哪些信息仍只能靠口头解释？
- 哪个部分看起来像研究报告，而不是工作工具？
- 哪项工作你不希望这个产品承担？

不问“你会不会用”“你喜欢吗”或“你愿意付多少钱”。

### 52–55 分钟：收尾

- 今天遗漏了哪个重要步骤或风险？
- 哪个问题让你觉得答案已经被暗示？
- 哪张卡或哪个界面词最难懂？
- 再次确认哪些笔记、原话或材料可以保留。

## 试访停止规则

发生以下任一情况时停止正式流程，并把本场标记为 `excluded` 或仅主持演练：

- 未取得匿名笔记同意。
- 参与者没有最近 6 个月的真实任务，且开始编造假想经历。
- 主持人连续三次以上解释产品概念或引导卡片选择。
- 原型关键功能无法加载，导致无法完成任务、路线、载体或导出旅程。
- 敏感客户、人脸、权利或个人信息无法被安全脱敏。

## 试访通过与改稿规则

试访不是判断产品成功，而是判断研究工具能否进入正式场次。

### 可以进入首场正式访谈

- 55 分钟内完成全部阶段。
- 参与者可复述至少 4/5 张盲测卡的主要保护对象。
- 主持人无需解释五类路线即可完成排序。
- 原型主旅程没有关键阻断。
- 记录表能区分原话、行为、材料、反证与研究员解释。

### 必须先改稿

- 两张卡持续只能靠研究员解释才能区分。
- 任一盲测卡超过 90 秒仍无法完成首次复述，或信息密度导致跳读。
- 参与者在看到用途标签前无法理解卡片，但看到示例后只是照抄答案。
- 参与者找不到完整对比、载体切换或导出中的任一关键步骤。
- 主持问题让参与者只给“是 / 否”“喜欢 / 不喜欢”而无法还原行为。
- 参与者把数字预演当作真实生成、可发布文件或实体效果证明。
