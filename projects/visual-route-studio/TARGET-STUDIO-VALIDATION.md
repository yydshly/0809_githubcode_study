# Target Studio 电脑网页探测版验证

## 验证结论

Target Studio Revision 4 已完成电脑网页探测闭环：一张统一 AI 原图可以进入五条多 Skill 组合样例，也可以接收任意产品目标；系统解释目标、合并相关研究 Skill 与本地扩展能力、显示完整 SOURCE → RESULT，并完成生成与导出状态。

当前网页是真实可运行的产品探测版，但不伪装成已经接入外部生成服务：ImageGen 用于生产项目内统一原图和组合结果样例；网页负责目标编排、结果装载、状态与导出。未来实时生成仍需要独立的后端、认证、费用与内容安全设计。

## 桌面布局

### 1440×900

- 左侧显示系统原图与目标入口，中间结果为最大视觉区域，右侧显示真实信息、能力组合和输出清单。
- 页面无横向滚动；左右栏独立滚动；中央结果与生成按钮保持可见。
- 陶艺明信片、工业文章封面和自定义多成品套件均进行截图观察，未见遮挡或越界。

### 1280×720

- 浏览器返回 `clientWidth = 1280`、`scrollWidth = 1280`，无横向溢出。
- 三栏继续成立；较低视口通过左右独立滚动访问完整设置。

## 可访问性与能力边界

- 所有目标、原图、标签页、方向、表单、生成和下载均使用语义 HTML 控件。
- `:focus-visible` 在语义聚焦时显示实线焦点环。
- 标签页支持左右方向键切换。
- CSS 已提供 `prefers-reduced-motion: reduce` 降级。
- 当前内置浏览器无法稳定注入连续原生 Tab，也无法模拟 reduced-motion 媒体偏好；这两项是非阻塞验证延期。换到具备对应能力的浏览器时复测，不影响当前鼠标主旅程与语义结构。

## 图片生成与前端边界

- 四组来源 contact sheet 使用内置 ImageGen 生成并复制到本项目，不依赖兄弟项目或已有线程图片。
- 生成提示要求虚构人物、面孔不可见、无品牌、无可读文字和水印。
- 当前网页不会把 Canvas 预演描述为真实远程 AI 生成。
- 真实生产版应在视觉生成层接入 ImageGen，并继续由确定性合成层处理真实文字、尺寸、来源和导出。
