# 用户访谈提纲

> **已后置**：本速查提纲对应历史路线决策原型。未来恢复研究时，应按 [DIRECTION_DECISION.md](DIRECTION_DECISION.md) 的 StoryFold 方向重写为照片故事任务研究，不可直接执行本版。

## 研究目的

了解创作者在真实视觉任务中如何选择方向、表达不可改变事实、判断概念图能否落地，并验证 Visual Route Studio 的路线决策价值。

## 招募建议

- 独立设计师 2–3 人。
- 摄影师或影像创作者 1–2 人。
- 内容创作者 1–2 人。
- 小型品牌或文化团队成员 1–2 人。

优先招募最近三个月实际完成过海报、封面、专题视觉或图片衍生品的人。不要只招募生成式图像爱好者。

## 开场说明

> 我们正在研究一个帮助创作者选择视觉处理路线的工具。今天测试的不是你的设计能力，也不是让你评价图片是否好看。我们想了解你在真实任务中如何作决定。访谈记录只用于本项目研究；涉及客户、人物或未公开素材时，请使用概括或虚构例子。

## 第一部分：还原最近任务

1. 请回忆最近一个从原始图片发展成海报、封面或其他产品的任务。
2. 原始素材由谁提供？你是否确定它可以用于最终发布？
3. 最终交付给谁、出现在哪里、需要哪些尺寸？
4. 哪些内容绝对不能改变？为什么？
5. 哪些部分允许重绘、删减或抽象？
6. 你最早探索了几个方向？如何排除？
7. 哪一步返工最多？当时缺少什么信息？
8. 你如何判断一张概念图已经能进入真实生产？

## 第二部分：路线卡片

给参与者一个真实或虚构任务，再使用 [ROUTE-CARDS.md](ROUTE-CARDS.md)：

1. 请先选两条可能路线，并说出理由。
2. 哪条路线风险最大？
3. 哪些词听起来专业但没有帮助？
4. 如果人数、文字或地点必须准确，你会改变选择吗？
5. 如果最终载体从海报改为网页或明信片，你会改变选择吗？

## 第三部分：低保真原型

让参与者完成以下旅程，不主动解释控件：

1. 选择一个任务。
2. 查看不可改变事实。
3. 选择一条路线。
4. 说出它会保留什么、损失什么。
5. 切换一个产品载体。
6. 导出创意简报。

观察并记录：

- 第一个点击的位置。
- 是否先看效果，还是先看路线解释。
- 是否理解“部分成立”和“不证明什么”。
- 是否能区分数字预演与真实产品。
- 导出前还希望补充什么信息。

## 结束问题

1. 这个工具最有价值的部分是什么？
2. 哪部分像研究报告，而不像产品？
3. 如果没有真实生成能力，你是否仍会使用它？在什么阶段？
4. 你愿意保存或分享什么：图片、比较、路线理由，还是完整简报？
5. 下一次使用时，你最希望它替你减少哪一种返工？

## 研究边界

- 不上传真实客户机密、证件、人脸档案或未授权照片。
- 不把参与者的偏好扩展为普遍结论。
- 不用“完成任务”替代真实发布、印刷或现场证据。
- 每次结论都记录样本、任务、原型版本和无法证明的内容。
