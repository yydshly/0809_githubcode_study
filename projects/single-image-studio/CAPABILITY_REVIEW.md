> 文档角色：历史 13 Skill 的只读审计附录。当前九类原子能力、候选引擎与状态分别以 [CAPABILITY_MAP.md](CAPABILITY_MAP.md)、[CAPABILITY_REGISTRY.md](CAPABILITY_REGISTRY.md) 和 [STATUS.md](STATUS.md) 为准；本文不得覆盖它们。
>
> 日期：2026-08-12  
> 范围：重新审查历史 13 个图片 Skill 对“上传一张图 → 选择创意效果 → 真实生成”的可迁移价值。本文只覆盖创意方法研究，不是完整单图任务目录，也不是上线能力声明。

## 结论先行

历史研究证明了多种创意视觉方法值得继续测试，但没有证明其中任何一项已经成为稳定的单图产品效果，也没有建立透明抠图、去背景、证件 / 报名照或背景清理所需的精确图像处理底座。

- 13 个 Skill 实际来自 12 个仓库；`gathered-scenes-zine-skill` 的历史快照包含“实景拼贴”和“场景蒸馏”两份独立 Skill。
- 研究站记录的 127 组 SOURCE → EFFECT 主要是本地概念研究、代码实验或数字预演，不是 127 次上游 Skill 运行，也不是 127 次可复现的当前模型测试。
- 当前工作树没有保留研究站的 `public/generated` 与 `lab/sources` 资产，无法仅凭文档重新目视验收全部配对。
- 历史上最接近本产品的一组本地证据，是同一张“雨夜修车铺”来源图对应的“手绘记忆重构”和“结构套色重组”两张结果。在该单一样例中视觉差异可见、方向可讨论，但记录不完整，只能算 E0。
- 旧工作台实现了图片编辑请求边界，却因缺少 API 凭据没有复验成功响应、结果库与下载，不能升级为可重复任务证据。
- 因此按当前统一口径，实用效果 U1 为 0，创意方向 E0 有、E1 为 0；R1-pipeline、R1-product-validation、R1-product-release、O1、G1、V1 与 Release Gate 均为 0。没有任务可以直接成为发布候选，也没有历史图片可以未经补证直接成为正式样例。

## 审查范围修正：13 个 Skill 不是完整单图能力目录

原 13 Skill 矩阵研究的是手绘记忆、材料转译、关系抽象、编辑拼贴与产品结构等**创意方法**。它没有覆盖以下独立的实用任务：

- 透明抠图 / 去背景与 RGBA PNG；
- 纯色换底、背景虚化与主体像素锁定；
- 标准底色头像、报名照与地区 / 证件 profile 驱动的官方证件照片检查；
- 背景清理、去杂物、换背景和扩图；
- 为上述任务提供的输入归一化、主体检测、Alpha Matting、边缘净化与确定性合成。

历史 Revision 17 所称“主体提炼”也不等于抠图。归档实现只在浏览器 Canvas 上压暗外围、保亮预设椭圆区域并叠加聚焦线与轮廓符号；它没有输出主体 mask 或 Alpha，没有处理发丝、毛发、孔洞、半透明、色边和多主体，也没有证明背景像素已被移除。历史“背景减法”因此只能算视觉聚焦预演，不能作为透明抠图、背景去除或证件照能力证据。

当前 `single-image-studio` 也没有引入分割模型、Matting 权重、人物 / 人脸资格检测、边缘净化或确定性 RGBA 合成实现。OpenAI Image API 的 masked edit 可用于生成式局部编辑，但不能代替像素级 Alpha Matting；`gpt-image-2` 当前也不支持透明背景输出。实用任务必须先建立独立底座并重新取证。

完整的双层任务目录、底层契约和首批失败边界见 [TASK_CATALOG.md](TASK_CATALOG.md)。本文件下方 13 项矩阵继续保留为创意 Skill 研究账本，不应再被解读为首版全部单图效果候选。

## 可迁移的能力，不可继承的承诺

### 现在可以迁移

- 用原创 `Source Card` 记录主体、数量、方向、色锚、不可丢失事实和敏感边界。
- 用原创 `Effect Contract` 分开记录 `must_keep`、`may_change` 与 `forbidden`。
- 将模型生成与确定性职责分离：模型负责无字视觉变化，代码负责来源记录、真实文字、尺寸与必要的锁定区域。
- 将历史主体、关系和色锚提取方法用于创意推荐或 QA；不得把这些高层描述冒充分割 mask、Alpha 或人脸资格检测。
- 生成失败时 fail closed；没有真实结果就不进入当前结果、不启用下载。
- 以缩略图可辨差异、来源可识别、失败原因和固定尝试次数评估效果，而不是统计效果数量。

### 不能从历史直接继承

- 任何上游 Skill 的稳定性、当前可安装性或运行成功率。
- 上游样图、本地研究站生成资产或历史参考图的公开再发布权。
- 生成式照片窗的像素保真、人物身份、物件数量、年代或档案真实性。
- 透明抠图、去背景、发丝 / 毛发 Matting、证件照规格、人脸几何锁定、背景清理或 mask 外像素不变能力。
- 屏幕半调等同于实体网印，或数字卡片等同于可打印/可邮寄产品。
- 旧工作台的“AI 推荐”：其本地上传路径主要按图片数量与硬编码样例规则工作，并未完成在线视觉理解。

## 进入首版的硬门槛

一个效果只有同时满足以下条件，才能从“测试候选”升级为“E1 效果候选”：

1. 使用本项目权利清楚的单图夹具重新生成，不依赖上游样图或归档预置图。
2. 预先声明适用夹具、预期拒绝夹具、分母与最低通过率；拒绝边界不算成功，也不与适用夹具混算。
3. 定向重试只用于诊断；进入正式复验前冻结一份生产输入契约和全局配方版本，任何改动都创建新版本，旧版本结果不得混入同一 E1 结论。
4. 冻结版本至少在三类适用单图上通过，且能在小缩略图中与其他候选明显区分。
5. 必须保留项没有丢失、替换或计数错误；这里的“连续性”指人数、主体类别、动作和关键身份线索，不主观宣称生物特征身份精确。身份敏感输入直接判为不适用。
6. 参考样例内容没有泄漏进用户结果；无意文字、水印、严重肢体/结构错误、主体裁断等缺陷会阻止结果进入候选。
7. 输入/输出 SHA-256、精确模型、生成日期、请求 ID、输入角色及各自 hash、画幅、质量、完整提示和条款核对日期可追踪。
8. 达到 E1 后只可进入内部受控参考目录；用户可见发布还要通过独立 Release Gate，生产上线还要达到 R1-product-release、O1、G1 与对同一正式 build 有效的 V1（或已批准的 `V1MigrationManifest`）。它们都不能由 E1 自动推出。

具体候选和实验协议见 [EFFECT_SHORTLIST.md](EFFECT_SHORTLIST.md)。

## 独立 Release Gate

任何用户可见样例都必须进入逐图发布 allowlist，并单列：`processing_allowed`、`public_display_allowed`、`commercial_marketing_allowed`。还需核对人物肖像/隐私、商标、艺术品、地点等第三方权利，确认项目代码与资产的对外许可、适用模型/服务条款和政策。真实用户图即使允许上传处理，也默认不得进入公共参考目录。
