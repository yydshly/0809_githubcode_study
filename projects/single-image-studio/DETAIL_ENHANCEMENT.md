# 本地细节增强

## 设计合同

- 入口：上传并确认图片后，选择“自然增强”。
- 主要用户：希望在不上传图片、不生成新内容的前提下，让普通照片更干净、稍清晰的桌面用户。
- 核心路径：选择自然增强预设或手动调整光色、轻度降噪和清晰度 → 生成 → 在结果页对比 → 下载经重开校验的 PNG/JPEG。
- 体验目标：参数名称直观；预设可解释；默认效果克制；原图永不覆盖；生成结果和下载文件来自同一渲染结果。
- 明确边界：这是确定性的本地像素处理，不识别人脸或物体，不补画纹理，不去划痕，不恢复失焦细节，也不宣称 AI 修复。
- 复用场景：自然增强与老照片基础整理共用同一像素实现；老照片的四个结果版本只冻结不同的公开参数，不引入第二套隐藏处理。

## 处理规则

- 轻度降噪使用 Alpha 加权的 3×3 邻域，只混合可见颜色并原样保留 Alpha。
- 清晰度使用受限的局部反差增强；透明像素的隐藏 RGB 和 Alpha 不改写。
- 两个参数均为 0–100，预设值保持克制；0 表示完全不执行对应处理。
- 像素处理发生在裁剪、缩放与光色调整之后、编码之前，因此页面结果、下载 bytes 与独立重开校验使用同一像素结果。

## 状态覆盖

| 状态 | 页面行为 |
| --- | --- |
| 默认 | “自然提亮”预设给出轻度光色与细节增强，仍允许手动调整 |
| 手动 | 修改任一参数后取消预设高亮，并写入撤销/重做历史 |
| 原始 | “原始光色与细节”将五个参数全部归零 |
| 处理中 | 沿用任务运行状态，不允许把未校验结果显示为成功 |
| 成功 | 结果页展示最终处理图，并允许原图/结果对比和下载 |
| 失败 | 保留原图与设置，不生成下载项，不自动重试 |

## 验证范围

- 纯函数像素测试：均匀区域、边缘、透明像素、参数边界、确定性。
- 渲染合同测试：参数进入 RenderPlan，处理在编码和重开校验之前完成。
- 产品测试：入口、文案、预设和控件存在，且没有 AI/修复能力误导。
- 浏览器人工检查：自然照片上分别观察降噪、清晰度、二者组合及归零结果；本阶段不使用真实用户照片。
