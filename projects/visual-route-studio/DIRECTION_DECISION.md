## 决定依据

前置研究不是一组孤立风格，而是一条已经成形的图片生产链：

> 照片理解 → 事实与关系提取 → 叙事规划 → 记忆 / 抽象 / 材料转译 → 图片生成 → 确定性拼版 → 产品封装 → QA。

当前本地研究覆盖 12 个去重仓库、13 个 Skill、127 组 SOURCE → EFFECT、129 个静态效果、2 个实时实验和 13 个产品系统预演。它足以支持“哪些能力可以互补组合”的产品判断，但不能证明用户采用、付费或留存。

完整能力组合见 [SKILL_COMPOSITION.md](SKILL_COMPOSITION.md)。

## 三个互斥产品方向

### A. StoryFold：照片故事成品机

- 用户任务：把一次旅行、活动或一段记忆，变成一套有起承转合的视觉作品。
- 能力组合：原照编辑、多人 / 多场景编排、记忆重绘、关系抽象、封面隐喻、材料化、明信片封装和确定性合成。
- 主要成品：六页图片小志、封面和双面数字纪念卡。
- 核心优势：几乎所有已研究能力都能承担明确页面职责，最终产物也容易理解和评价。
- 核心风险：需要控制跨页一致性、人物事实、授权和生成成本。

### B. Campaign Forge：单张照片宣传套件

- 用户任务：把一张主照片发展为海报、社交封面和活动视觉套件。
- 能力组合：极简隐喻、点阵材料、编辑排版、原照锁定和多比例合成。
- 主要成品：一组多尺寸宣传图片。
- 核心优势：输出直接，工程边界较清楚。
- 核心风险：与 Canva、Adobe、Recraft 等现有多尺寸生产工具重叠较高；记忆与多照片能力无法充分发挥。

### C. Evidence Canvas：照片关系叙事图

- 用户任务：把照片、地点、时间与关系整理成可阅读的视觉报告。
- 能力组合：事实提取、关系蒸馏、代码图形、原照锁定和编辑排版。
- 主要成品：长图、展板或数字报告。
- 核心优势：结构差异化较强，适合文化、教育或档案题材。
- 核心风险：需要真实数据、内容编辑和领域验证；事实与隐喻的边界更难管理。

## 已选方向

选择 **StoryFold**。

它不是“让用户挑 13 个 Skill”，而是让 13 个 Skill 在后台承担不同职责：

1. 先把照片和用户说明整理为 Story Card 与 Evidence Card。
2. 根据故事节奏给每张照片分配开场、展开、转折或收束角色。
3. 生成“现场叙事”和“记忆叙事”两套故事板。
4. 按页面职责调用原照、重绘、抽象、材料和封面能力。
5. 用原创确定性合成器放回真实照片、文字、页码和统一版式。
6. 输出一套连续作品，而不是互不相关的风格样张。

## 第一版产品边界

### 必须完成

- 4–8 张照片的一次性项目输入。
- 每张照片选择“必须原样 / 允许重绘 / 允许抽象”。
- 两套有清楚差异的六页故事板。
- 封面、原照页、拼贴页、记忆页、关系页与收束页。
- 六张 4:5 页面 PNG、独立封面 PNG、2:3 双面数字纪念卡。
- 真实文字、照片顺序、来源记录、尺寸和安全区的确定性合成与 QA。
- 单页重做，避免一页失败导致整本重新生成。

### 明确不做

- 13 个 Skill 按钮、模型市场或第三方 Skill 安装器。
- 通用自由画布、任意页数或全能设计代理。
- 自动猜测人物关系、事件顺序、历史事实或素材权利。
- 面孔相似、纪实真实性、文物修复或法律合规保证。
- 首版中的实体印刷、装订、二维码、邮寄和商业生产承诺。

## 旧方向如何保留

| 旧研究资产 | 在新方向中的位置 |
| --- | --- |
| `must preserve / may change` | 转为每张照片的转换权限与 Evidence Card 字段 |
| SOURCE / EFFECT 对照 | 用于原照区域和生成页面的内部 QA |
| Route Contract | 收敛为 Story / Evidence Card，不作为独立产品界面 |
| Handoff Bundle | 转为包含 PNG、PDF、真实文字和来源记录的交付包 |
| 历史路线决策原型 | 仅保留为研究历史，不代表 StoryFold MVP |

## 需要后续证伪

StoryFold 仍是 D0 产品假设。后续必须验证：六页成品是否比普通模板相册更有价值；两套叙事路线是否容易理解；用户是否愿意补充故事事实与转换权限；跨页一致性和单页重做是否足够可靠。研究计划见 [RESEARCH.md](RESEARCH.md)。
