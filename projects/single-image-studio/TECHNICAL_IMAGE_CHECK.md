# 图片技术检查与处理建议

## 设计合同

- 模式：Functional / Editorial Flow。
- 入口：上传、确认图片并完成文件解码后，在任务列表之前显示。
- 核心路径：本机缩小取样 → 显示曝光分布、色彩倾向与局部变化三个可解释观察 → 给出一个保守的处理起点 → 用户明确点击后才进入对应工具。
- 体验目标：先帮助用户理解“可以从哪里开始”，再展示完整任务目录；检查过程不阻断任务选择，建议不会自动改图。
- 明确边界：只计算像素分布，不识别人、商品、证件、场景或照片质量，不调用网络，不作专业测光、白平衡或清晰度鉴定，也不把启发式建议描述成 AI 判断。
- 失败回退：解码、画布或像素读取失败时显示“技术检查未完成”，但完整任务目录仍可使用。

## 可见信息

| 观察 | 计算依据 | 页面用语边界 |
| --- | --- | --- |
| 曝光分布 | 可见像素亮度均值、暗部与高光占比 | “整体偏暗 / 偏亮 / 分布较均衡”，不称曝光正确或错误 |
| 色彩倾向 | 非极暗、非极亮像素的 RGB 通道均值差 | “偏暖 / 偏冷 / 偏绿趋势 / 通道较接近”，不称已校准白平衡 |
| 局部变化 | 相邻像素亮度差的均值 | “变化较少 / 适中 / 较多”，不称失焦、噪点或画质好坏 |

## 建议规则

- 整体偏暗：建议从自然增强的“清亮”预设开始。
- 整体偏亮或局部变化较多：建议从“柔和降噪”开始。
- 其他情况：建议从“自然增强”开始。
- 所有建议都必须显示理由和“只是起点”说明；只有用户点击“打开并使用建议”后才写入公开参数。

## 状态覆盖

| 状态 | 页面行为 |
| --- | --- |
| 检查中 | 卡片显示本机技术检查进行中，任务目录可先显示 |
| 可用 | 显示三个观察、建议预设、理由和显式操作按钮 |
| 不可用 | 显示非阻断说明，不隐藏或禁用任何任务 |
| 换图 / 取消 | 清除旧观察；旧异步结果不得覆盖新来源 |
| 返回任务页 | 复用当前来源的观察，不重复检查 |

## 验证范围

- 纯函数测试覆盖暗、亮、通道倾向、局部变化、透明像素和输入边界。
- 页面合同测试覆盖可见边界、显式按钮、无网络/无语义识别文案和失败不阻断。
- 自动产品测试验证旧来源结果不会写入新来源状态。
- 视觉与交互验收需要在真实浏览器中复核桌面、窄屏、键盘焦点和长文案换行；没有浏览器控制证据时不得宣称已完成视觉验收。
